
# Анализ каталога фильмов

Домашнее задание по Python — анализ каталога из 10 фильмов.

Программа обрабатывает информацию о фильмах:
названия, годы выпуска, жанры, рейтинги,
продолжительность и актёров.

## Возможности программы

- Вычисление среднего рейтинга и возраста фильмов.
- Определение категорий рейтингов.
- Обработка названий фильмов.
- Сортировка фильмов по рейтингу.
- Поиск трёх лучших фильмов.
- Подсчёт фильмов по жанрам.
- Анализ фильмографии актёров.
- Работа с множествами и генераторами.
- Формирование итогового отчёта.

## Требования

- Python 3.12 или новее.
- uv.

## Установка

В папке проекта выполните:

```powershell
uv sync
```

## Запуск программы

```powershell
uv run catalog_analysis.py
```

Программа выводит итоговый отчёт:
средний рейтинг, средний возраст,
топ-3 фильма и статистику по жанрам.

## Проверка кода

Проект использует Ruff.

```powershell
uv run ruff check .
```

## Структура проекта

- `catalog_analysis.py` — основной код программы.
- `pyproject.toml` — настройки проекта и Ruff.
- `uv.lock` — файл фиксации зависимостей.
- `.gitignore` — исключения для Git.
- `README.md` — описание проекта.
